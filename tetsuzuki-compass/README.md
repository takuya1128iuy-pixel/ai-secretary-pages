## 直さない・消さない

- **直さない。** 直すのはソース側。ここへ手で直しても本番と二重管理になる。
- **消さない。** リンク切れになる相手がいないかは、まだ確かめきれていない。
  判断は持ち主が行う。

LINEのリッチメニューについては、**2026-09-07 の反映以降ここを指していない**（本番の
Cloudflare を向いている）。リッチメニューはLINE側の1つの定義を全員が見るしくみなので、
先に友だち追加した人のメニューも同時に切り替わっている。
つまり「LINEのメニューがここを向いているから消せない」という理由は、もう成り立たない。
